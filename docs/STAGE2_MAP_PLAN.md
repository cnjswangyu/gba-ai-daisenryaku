## 固化的地图功能

模拟器已加载 `lua/native_attack.lua` 时，在出击编成界面双击项目根目录的 `View-Map.cmd`，即可发送游戏 R 键、导出地图和军表、生成全图 PNG。

```powershell
.\View-Map.cmd
python tools/view_map.py --output shots/stage2_map --title "军事演习2：完整地形与敌方部署"
```

也可单独调用：

```powershell
python tools/native_attack.py VIEWMAP
python tools/native_attack.py MAPSCROLL Up 3
python tools/native_attack.py MAPSCROLL Right 2
python tools/native_attack.py MAPDATA
python tools/map_overview.py --output shots/stage2_map
python tools/native_attack.py KEY B 4 50
```

`VIEWMAP` 已在出击编成 `state=6` 实测，调用游戏 R 肩键，B 返回军表。`MAPSCROLL` 每步按住 14 帧并松开 8 帧；步数表示输入脉冲次数，不保证恰好一格。4 帧的短方向输入在这张预览里可能无法移动光标。

`VIEWMAP` 不等于旧命令 `MAP`：旧命令是退出菜单回可操作地图。当前键位文件的 GBA R 映射为键盘 E；命令发送的是模拟器控制器 R，不依赖键盘映射。

数据输出为 `shots/native_attack/map.json`，含 48×48 格的原始地形/耐久/归属/flags、军表、双方单位与经验。图片是根据这些数据生成的分析图，**包含从内存读取的敌军位置，不代表 R 预览本身显示了全部敌军**。

地形耗费读取原 ROM：分类表指针 `0x080026D4`，普通表 `0x08046F26`，建筑表 `0x08046FC6`。本次用游戏底栏核对到 `0x0C` 是海面、`0x01` 是平地，修正了主脚本旧名称；中央大片 `0x06` 对履带类别 2、步兵类别 4 的耗费均为 0，即不可通行。

## 战术次序

1. 留一辆 M1A2 占住己方首都；主力从中央山地两侧绕行，避免全军堵在同一入口。
2. 两路保持坦克在前、火炮后置、步兵和补给居后；向 `(24,17)`、`(26,17)` 一带汇合。
3. 接敌时优先消除敌方射程 3 的四门火炮，并用实际伤害读回集中收掉残血；不把攻击力直接视为扣血。
4. 贴身威胁中优先处理反坦克车，随后同回合集火坦克；敌军在建筑上也需要协同击杀，避免每回合只打一发。
5. 清空敌方首都后让步兵占领，或全歼后接受原生投降。胜利仍需 `state=8` 且 `ctx+0x2C=2`。

当前 `AUTOCLEAR` 会写第一关命名的回合/胜利文件，且战术只在第一关验证。开始第二关全自动之前，应隔离第二关存档和日志，并验证推进/补给流程。
