# 占领（占領）系统逆向 —— 完整证据链

> 当前一键流程及完整通关验证见 [PLAY_STAGE1.md](PLAY_STAGE1.md)。胜利必须核验 `state=8` 且 `ctx+0x2C=2`；`ctx+1==2` 只能作为流程变化信号。

> 2026-10-18。目标：不用按键，纯逆向实现“步兵占领城市/敌方首都”。
> 全部结论来自 Ghidra 反编译 + 运行时 A/B 实测。

## 1. 地形格数据结构（每格 4 字节）

地形表基址 = `*(ctx+0x18)`（本剧本 = `0x020071B0`），格子地址 = `基址 + x*4 + y*0xC0`：

| 偏移 | 含义 | 实测样例 |
|---|---|---|
| +0 | **地形码** | 0x10 首都 / 0x11 市街 / 0x14 村落 / 0x0C 平地 / 0x8B 森林 |
| +1 | **城市 HP（耐久）** | 首都 0xFA=250 / 市街 0x96=150 / 村落 0x64=100（每回合回复 → “蹲城回血”的根源） |
| +2 | **归属阵营** | 1 = 我方，2 = 敌方 |
| +3 | flags | bit1 由占领逻辑清除（`&= 0xFD`） |

实测全图建筑格（20 单位美国局）：我方首都 (21,30) = `10 FA 01 00`；敌方首都 (27,14) = `10 FA 02 00`；其余 14 座建筑 `02`（敌）。

## 2. 可占领地形判定

```c
bool FUN_080026d8(int terr) { return (terr - 0x10U) < 0x19; }
```
→ **terr ∈ [0x10, 0x28]，共 25 种建筑类地形全部可占领**（首都/市街/村落/工厂/机场/港口…）。
这就是“步兵可以占领很多地形”的实现依据；同时它也是移耗表 B 的适用范围，说明建筑类地形共享一套判定。

## 3. 占领执行函数

单位行动菜单分派器 `FUN_0801e33e`（每帧输入处理）按菜单项 ID 分支：

| ID | 动作 | 落地实现 |
|---|---|---|
| 0x10 | 移动路径光标 | 更新路径点 |
| 0x12 | 移动确认 | 格表[阵营+1/槽号+1] + 记录 x/y + `FUN_0801F130`(acted) + `FUN_0801F078`(燃料) |
| **0x22** | **占領** | **`FUN_08020b20(side, slot)`** |
| 0x24 | 其他动作 | `FUN_080207a4(a,b,c)` |
| 0x26 | 其他动作 | `FUN_08020f14(side, slot)` |
| 0x20 / 0x2a | 装卸/待机 | 格表写入 / 其他 |

### FUN_08020b20(side, slot) —— 占領主函数

```c
u = ctx + side*0x600 + 0x2760 + slot*0x18;        // 单位记录
cell = *(ctx+0x18) + y*0xC0 + x*4;                // 所在格
if (cell[0] == 0x10) {                            // ---- 首都分支 ----
    (ctx+0x24 + side*0xC) += 表[首都收入];          // 收入
    FUN_080209c8(side, owner-1);
    if (FUN_08017854(0, owner-1, side) == 1) {    // ★ 胜利判定
        ctx[1] = 2;                               // 进入结束流程
        ...
    }
} else {                                          // ---- 普通建筑 ----
    (ctx+0x24 + side*0xC) += 表[terr-0x10];        // 收入（市街=100）
    cell[2] = side + 1;                           // ★ 归属翻转（HP 不动！）
    if (FUN_080026d8(cell[0])) {                  // 可占领地形
        FUN_08002f24/FUN_08002f9c/FUN_08002fd0(x, y, 表值, flag);  // 地图归属/雷达刷新
    }
    ... （敌方单位驱离处理）
}
```

要点：
- **占领 = 归属字节翻转**，城市 HP **不变**（与实测完全一致：`11 96 02 00` → `11 96 01 00`）。
- 占城立即拿钱：`资金 += 表[地形-0x10]`（市街 100）。
- **占首都直接触发胜利判定** `FUN_08017854` → 胜利条件文本 `占領敵方的首都`（ROM 0x08045FB0）。
- 另一个入口 `FUN_08020f14(side, slot)`：`cell[2]=side+1`、`cell[1]=min(100, FUN_08002b28(x,y))`、`cell[3]&=0xFD`（设施类路径）。

## 4. 桥命令 CAP（纯汇编调用，零按键）

```
CAP <槽号>      # 要求：单位未行动 且 站在可占领地形(0x10..0x28) 上
```
实现：`native_call(0x08020B20, {0, slot})` → 读回归属/资金 → `FUN_0801F130` 置 acted。
**注意**：`FUN_08020B20` 内含 UI/状态切换，调用后**不能**再叠加原生重绘 `FUN_08016BE0`（会挂死在 `PC=0x080006C2`）。

实测（stage1_v2_deployed，美军第一关）：

| 命令 | 结果 |
|---|---|
| `POSITION 13 17 30` | OK 瞬移 U13 (20,32)→(17,30) |
| `CAP 13` | **OK 占領(17,30) 归属2→1 资金1441→1541** state=7/1（游戏稳定，无崩溃） |
| `CAP 13`（重复） | 正确拒绝：已行动 |
| `CAP 0`（坦克在平地） | 正确拒绝：地形不可占领 |

## 5. 战术含义（对应实战反馈）

1. **打敌方首都 = 一个一个送死**：首都有守军（T-72B），且城市每回合回血 → 消耗战必败。
   正解：**集中火力一击必杀清守军 → 步兵/空降兵进入首都 → CAP → 直接胜利**。
2. **敌人蹲城不喂**：评分规则加铁律“敌在建筑格且打不死 → 不打”（`on_building(e) and not kill`）。
3. **步兵占城**：步兵/空降兵（id 305/324）在无攻击方案时优先占领可达建筑，按“朝敌首都方向”选点，
   拿钱 + 断敌方补给点。
4. 胜利判定两种：全歼敌军（现有）或 **占据敌方首都**（`ctx+1==2` / `state==8`）。
